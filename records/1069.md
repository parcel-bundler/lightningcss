# #1069 Range syntax in container style queries

**Feature request, keep open, medium.** `@container style(--x > 10)`, `style(1em < 20px)`, `style(10 < --x <= 20)` and the same inside `style((…) or (…))` error in strict mode on master and 1.31.1–1.33.0. `errorRecovery` keeps the rule as written with a warning, so that part is fine.

- Spec: css-conditional-5 ED adds `<style-range>` to `<style-feature>` (operands: custom property name or `<declaration-value>`, resolved at evaluation time).
- Support (MDN BCD 8.0.7): Chrome 142, Firefox 151, Safari no. Two engines have shipped it, so implement it as a regular feature with no draft flag.
- Fix: medium. Add a `StyleQuery::Range` variant in `src/rules/container.rs` and reuse `MediaFeatureComparison` from `media_query.rs`. Operands are stored as a property name or `TokenList`. The JS AST change only adds a union case.
