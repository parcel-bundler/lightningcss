## Draft reply

Good news: the main request was implemented in 1.21.0. A hand-picked fallback before a modern value is now kept, e.g. `color: #4263eb; color: color(display-p3 0 .5 1)` is output unchanged for Chrome 95. Values inside a matching `@supports` don't get generated fallbacks, and gradient and `image-set()` fallbacks are kept too.

Custom properties are a special case: with `--link: a; --link: b` every browser uses the last value, so the first one never acts as a fallback. Wrapping the modern value in `@supports (color: color(display-p3 0 0 0))` is the way to hand-pick it, and that works.

The original `@media (dynamic-range: high)` example currently loses the display-p3 value. That's a separate bug since 1.30.0, tracked in #1381 (open PR #1386). Closing this one in favour of that, but feel free to reopen if something else is missing.
