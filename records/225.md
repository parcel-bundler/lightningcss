## Draft reply
Status update: master still only merges adjacent rules (`body{...}h1{...}body{margin:0}` keeps two `body` rules). Merging across other rules is safe only when nothing in between can set an overlapping property; that includes shorthands/longhands, logical/physical pairs like `width`/`inline-size`, `all`, and rules inside `@media`/`@supports`/`@layer`. Your example meets that condition. Non-adjacent rules with the same selector *and* the same properties are already handled: the earlier one is dropped.

We measured the potential on real stylesheets (Bootstrap, Bulma, Primer, Radix Themes, Pico and others): merging same-selector rules saves under 0.05%; merging rules with identical declarations saves up to about 1% before compression (mostly Bulma's generated color variants). An opt-in mode that ignores the cascade is still an open question: it can silently change rendering, so it would need a careful design.
