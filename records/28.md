# #28 Split file by media query

**feature, feature-request, low, needs-maintainer-decision (lean: close with workaround)**

- Splitting output files is a bundler/HTML concern. `transform()` has one output, and splitting reorders rules (cascade risk, `@layer` order).
- Non-matching `<link media>` files are still downloaded, so the gain is only that they don't block rendering.
- It is doable today in userland. `28-repro.mjs` pins a two-pass approach: lower nesting with targets, then a `StyleSheet` visitor that filters top-level `@media print`. It's verified on master and 1.31-1.33. One pass isn't enough because visitors run before nesting is lowered.
- One 2026 comment asks for a print split; there are no duplicates.
