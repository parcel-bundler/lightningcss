## Draft reply

Since v1.23.0 you can get the full parsed AST from Node using the `StyleSheet` visitor:

```js
import { transform } from 'lightningcss';

function parse(code) {
  let ast;
  transform({
    filename: 'style.css',
    code: Buffer.from(code),
    visitor: { StyleSheet(sheet) { ast = sheet; } }
  });
  return ast;
}
```

The result follows the types in `lightningcss/node/ast.d.ts`: values are fully typed (e.g. colors come back as `{type: 'rgb', r, g, b, alpha}`), and rules have a `loc`. Invalid CSS throws, or becomes a warning with `errorRecovery: true`. Two caveats for linting: converting the whole AST to JS objects is slower than visiting only what you need, so specific visitors (e.g. `Declaration: { color() {} }`) are still preferable, and individual declarations don't have source locations.
