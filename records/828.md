## Draft reply

This can be turned off with the `LightDark` feature flag: pass `exclude: Features.LightDark` to `transform()` (or Vite's `css.lightningcss.exclude`), and Lightning CSS keeps `light-dark()` as written and no longer adds the `--lightningcss-light`/`--lightningcss-dark` variables. Raising your targets to browsers with native support (Chrome 123, Firefox 120, Safari 17.5) has the same effect. The flags are listed at https://lightningcss.dev/transpilation.html#feature-flags.

If you're turning it off because colors don't follow a nested `color-scheme`, that's tracked in #821. Custom variable names were discussed in #708: the shared names let separately compiled stylesheets work together.

Closing since this is supported, but feel free to reopen if the flag doesn't cover your case.
