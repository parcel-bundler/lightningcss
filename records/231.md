# #231 option to keep declaration order

**feature, low, needs-maintainer-decision.** Non-minified `transform()` still runs `StyleSheet::minify`, so declarations are regrouped by handler (custom properties pulled together, `display` moved last) and `!important` declarations go last. All observed reorderings are cascade-equivalent, so this is cosmetic. Meaning-changing reorders are tracked in #572 and others. A cheap option: skip `minify()` when `minify: false` and there are no targets. Preserving order in the handlers is large.
