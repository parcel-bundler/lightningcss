# #610 Consider adding --watch to the cli

**feature, feature-request, low, needs-maintainer-decision.**

- Confirmed missing: master's CLI (`src/main.rs`, clap) has no watch option, and no PR attempts it. Related #126 (2022) was answered with external watchers (watchexec, npm-watch).
- Demand: 22 reactions and several +1s, mostly from people using the standalone binary without Node.
- Philosophy: neutral. This is CLI scope, not CSS syntax. The case for building it in is `--bundle`: a built-in watcher could watch the actual `@import` graph (the Bundler already loads every file), which an external glob watcher can't do precisely. The costs are a new dependency (e.g. `notify`), debouncing, output-loop avoidance and cross-platform maintenance.
- Rough size: medium. No draft reply, because the answer depends on the maintainer's scope decision. If declined, a reply should point to `watchexec -e css -- lightningcss ...`.
