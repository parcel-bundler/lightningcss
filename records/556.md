## Draft reply

Both directions are possible with the current JS API (v1.23.0+), using the `StyleSheet` visitor:

```js
import { transform } from 'lightningcss';

// CSS -> AST
let ast;
transform({ filename: 'a.css', code: Buffer.from(css), visitor: { StyleSheet(s) { ast = s; } } });

// AST -> CSS: return the AST and transform prints it
let { code } = transform({ filename: 'b.css', code: Buffer.from(''), visitor: { StyleSheet() { return ast; } } });
```

To get the text of a single declaration you captured in a visitor, put it into a placeholder rule the same way (e.g. a `Rule.style` visitor on `.x{}` that sets `declarations: {declarations: [decl], importantDeclarations: []}`). To go the other way inside a visitor, return `{ property: 'color', raw: 'red' }` (or `{ raw }` for tokens) and it is parsed for you. Note the output is normalized, not byte-identical to the input.
