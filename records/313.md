# #313: Minification can benefit from using single quotation marks on strings

**feature / feature-request / low / action: needs-maintainer-decision**

Strings and url() are always written with double quotes, so any `"` inside gets escaped even when single quotes would need no escapes. Both forms parse to the same value; choosing the quote that needs fewer escapes is a safe size win when minifying.

**Evidence:** Round-trip checked in the repro via a second transform; Chromium 153 parses `'a"b"c'` and `url('a"b')` to the same value as the double-quoted forms (CSSOM re-serializes both with double quotes, as CSSOM requires). Escape terminators: Chromium distinguishes `"\a  b"` (newline, space, b) from `"\a b"` (newline, b), relevant to PR #1025.

**Repro:** 313-repro.mjs. `.a{content:url('data:image/svg+xml,<svg xmlns="..." width="16">...')}` -> `url("data:image/svg+xml,<svg xmlns=\"...\" width=\"16\">...")`; `content:'say "hi"'` -> `"say \"hi\""`; `font-family:'My "Quoted" Font'` -> escaped. All outputs round-trip (re-parse equal). Same on local, 1.33.0, 1.32.0, 1.31.1. Controls (no inner quotes, apostrophes only) correctly stay double-quoted.

**Fix:** In minify mode, count `"` vs `'` and pick the quote with fewer escapes, delegating all other escaping to cssparser's CssStringWriter (keeps hex-escape terminators correct). Apply to url() first (PR #1338), then generalize to CSSString/FamilyName/attribute values/token-list strings if wanted.

URL-only and minify-only; single-quote writer handles only the quote characters and delegates everything else to CssStringWriter, so escape terminators stay correct; ties keep double quotes; dependency placeholders and non-minified output unchanged.
